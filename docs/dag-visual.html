What is SHARED across every node

  • client.py — the one MCP client (login + call). All nodes use it to talk to the platform.
  • The 4-step loop machinery (perceive→decide→act→check).
  • Memory — facts, recipes, preferences.
  • The state dict — the shared notebook that flows through the graph.

What is PRIVATE to each node

  • Its system prompt (its personality + job).
  • Its tool subset (Publisher can write; Verifier is read-only).
  • Its narrow task — it does NOT need the whole picture, just its slice + the state keys it reads.

The shared “notebook” (state dict) as it fills up

  • start: { request: "..." }
  • after PUBLISHER: { ..., published_post_id: "abc", post_title: "..." }
  • after ANALYST: { ..., dead_pages: [...], definition: "orphan pages", caveat: "no view data" }
  • after VERIFIER: { ..., verdicts: { publish: PASS, dead_pages: PASS } }
